# Simple Games

This is a collection of games meant to be used to pass time and provide competition through a leaderboard. 

## How to Use the Project

1. Choose a game
2. Follow the instructions of the given game
3. Repeat

## Key Features

- Snake
- Hangman
- Minesweeper

## Instalation Instructions

1. Install pygame using "pip install pygame"
2. Install tkinter using "pip install tkinter"
3. Install faker using "pip install faker"
